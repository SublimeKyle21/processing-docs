# Processing Docs

A community reference for the [Processing](https://processing.org/) API — covering every function, renderer behavior, edge cases, and gotchas in one place.

## Structure

| Folder | Contents |
|--------|----------|
| `core/` | Lifecycle, environment, and control functions |
| `shapes/` | 2D/3D primitives, curves, vertex operations |
| `transforms/` | Matrix, rotation, scale, translation |
| `images/` | Loading, displaying, and manipulating images |
| `text/` | Typography and font functions |
| `graphics/` | Color, fill, stroke, blending |
| `renderers/` | `createGraphics`, off-screen buffers |
| `lighting/` | 3D lighting and materials |
| `shaders/` | GLSL shader integration |
| `math/` | Calculation, trig, random, PVector |
| `io/` | File loading/saving (strings, bytes, JSON, XML, tables) |
| `sound/` | Processing Sound library |
| `utilities/` | Conversion, arrays, strings, time, output |
| `pitfalls/` | Common mistakes, renderer quirks, performance tips |
| `examples/` | Annotated reference sketches |
